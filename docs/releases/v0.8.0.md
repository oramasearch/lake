# v0.8.0

2026-10-26. A minor release: agents work on the latest GPT again, and Apps can be changed from the console.

## What it includes

- **Agents on gpt-6.1-sol** ([lake#1245](https://github.com/oramasearch/lake/issues/1245),
  [#1253](https://github.com/oramasearch/lake/pull/1253)). OpenAI refuses function tools together with
  `reasoning_effort` on `/v1/chat/completions` for the gpt-6 models, so every agent turn with tools failed on
  v0.7.2. The model gateway now sends such a request (gpt-6.1-sol, gpt-6.1-terra, gpt-6-astra, gpt-6-luna, with
  `tools`) to `/v1/responses` and translates the answer back to a chat completion: tool calls, tool results,
  `finish_reason` and usage, which is billed exactly as before. gpt-5.5, and gpt-6 calls without tools, stay on
  Chat Completions. The default agent model is gpt-6.1-sol again ([model gateway](../api/model-gateway.md)).
- **Edit a repository file** ([lake#1239](https://github.com/oramasearch/lake/issues/1239),
  [#1246](https://github.com/oramasearch/lake/pull/1246)): Edit on a text file's preview for people who may
  write to the repository, commit with a message, and *Commit and redeploy* for a file inside an App's source.
  A file changed on the branch since it was opened is a conflict (`expected_blob` on `commit_repository_files`),
  never overwritten. Files are read from `content_base64`, so non-ASCII bytes stay exact.
- **A conversation that changes an App** ([lake#1240](https://github.com/oramasearch/lake/issues/1240),
  [#1247](https://github.com/oramasearch/lake/pull/1247)): a multi-turn thread per App, kept in the workspace;
  Confirm commits and redeploys, and the thread goes on. New capability `get_app_conversation`; the agent
  receives the earlier turns as `history` (agent-application v0.2.4 reads them).
- **Change App split screen** ([lake#1241](https://github.com/oramasearch/lake/issues/1241),
  [#1252](https://github.com/oramasearch/lake/pull/1252)): the conversation beside the running App, which
  reloads once a confirmed change is deployed and Ready.
- Everything in [v0.7.3](v0.7.3.md) except its gpt-5.5 default, including the version header fix
  ([#1251](https://github.com/oramasearch/lake/pull/1251)).

## Not included

- Streaming a gpt-6 request that carries tools is answered from the Responses stream; no library agent streams
  with tools today.
- Any origin can still frame an App: restricting `frame-ancestors` to the Lake's own origin is an operator
  change, not in this release.
