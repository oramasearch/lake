# Front-door browser evidence

Native Chrome captures at 1280 and 640 pixels in light and dark, against the local PostgreSQL-backed
Lake. Each profile starts signed out, opens the homepage's Create account action, signs up with a
fresh public Liquid identity document, and creates its first private repository. Screenshots show
the initial forms and repository, with no passwords, session cookies, or issued token values.

The navigation matrix, copy, walkthrough, and native verification are in
[../../front-door.md](../../front-door.md). Homepage captures use the final card and action-row
layout. Repository captures show the first empty repository before any content is pushed.
