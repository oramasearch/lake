lake

The lake binary. The hosted service at lake.live — forge, drive, platform, identity, secrets, PKI, artifact registry and search — over one content-addressed store.

liquid is the tool. lake is where it collects.

Build and run

cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build
./build/lake --listen 127.0.0.1:4900

What this is

One C++26 binary. Enterprise control plane on Postgres, repository data through libliquid, and server-rendered pages using one capability registry.
